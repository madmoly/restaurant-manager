## 1. WorkSummaryPage — 인원별 요약 카드 + 세부 근무내역 인라인

### 결정
- 데스크톱 매트릭스 (월×인원 그리드) **폐기**.
- 데스크톱·모바일 모두 **인원별 요약 카드** 한 형태로 통일.
- 카드 펼침 = 그 자리에 **세부 근무내역 테이블** 인라인 표시 (현 ShiftDetailDialog 콘텐츠).
- ShiftDetailDialog **폐기**, 미니캘린더 **폐기**, "세부" 버튼 **폐기**.

### 변경 내역
1. `DesktopMatrix` 컴포넌트 삭제.
2. `MiniCalendar` 컴포넌트 삭제.
3. `ShiftDetailDialog` 컴포넌트 삭제. 내부 테이블 마크업·`PRESET_LABEL`·`STATUS_LABEL` 매핑은 새 인라인 렌더에 흡수.
4. `MobileEmployeeRow` → `EmployeeShiftCard`로 개명, 데스크톱·모바일 공용. `md:hidden` 분기 제거.
5. 회사 카드 펼침 영역의 데스크톱 분기(`hidden md:block` 매트릭스 래퍼) 삭제, 분기 없이 `EmployeeShiftCard` 리스트만 렌더.
6. `EmployeeShiftCard` 펼침 콘텐츠를 다음으로 교체:
   - 미니캘린더 → 세부 근무내역 테이블 (날짜 / 시간 / 휴게 / 순근무 / 유형 / 상태).
   - 데이터 소스: `trpc.schedules.employeeMonthlyShifts.useQuery({ restaurantId, year, month, userId, tempWorkerName })`.
   - `enabled`: 카드가 펼쳐진 상태일 때만(현재 모달의 `enabled` 로직 그대로 카드 단위로).
   - 상단 요약 (근무일·총 근무시간) 2열 박스 유지.
7. 페이지 상태:
   - `expandedEmpKey: string | null` 유지 (한 번에 한 카드만 펼치도록 권장).
   - `detailTarget`, `setDetailTarget` 삭제. 대신 펼친 카드가 직접 자기 `userId/tempWorkerName` 으로 쿼리.
8. import 정리: `Dialog/DialogContent/DialogHeader/DialogTitle`, `Eye`, `X` 사용처 제거 후 import 삭제. `useMemo`도 미니캘린더 제거 후 미사용이면 삭제.

### 카드 펼침 UI 권장

## 2. LaborCostPage — "정산내역 포함" → "노무사전송용 (시스템 계산 급여 제외)"

### 결정
- 라벨·의미·컬럼 구성을 모두 교체.
- 체크박스 ON = **노무사전송용 모드**: 시스템이 계산한 급여(인건비/주휴/연장/야간/3.3%공제/실지급) 제외, 계약·근무·신원 raw data만 출력. 노무사가 직접 정산하기 위한 입력 자료.
- 체크박스 OFF = **기본 정산 보기**: 시스템 계산 결과 포함(현재 `fullHeaders`와 동일).
- 기존 OFF 모드의 `basicHeaders`(출근/휴무만)는 폐기.

### 변경 내역
1. 상태 변수 `includeSettlement` → `consultantMode` (또는 `payrollExportMode`).
   - 기본값 `false` (기본 정산 보기 = 풀 컬럼).
2. 체크박스 라벨 텍스트 교체:
   - 기존: `정산내역 포함`
   - 신규: `노무사전송용 (시스템 계산 급여 제외)`
3. 헤더·rows 분기 재정의:
   ```ts
   const fullHeaders = ["소속회사","이름","직위","급여유형","계약급여","계약휴무","출근일수","실휴무일","대체휴무잔여","연차잔여","보험구분","인건비(원)","3.3%공제","계좌번호","주민번호","계약시작","계약종료"];

   const consultantHeaders = ["소속회사","이름","직위","급여유형","계약급여","보험구분","출근일수","실휴무일","계약휴무","대체휴무사용","대체휴무잔여","연차사용","연차잔여","계좌번호","주민번호","계약시작","계약종료"];
   ```
4. `buildRows(consultantMode)` 시그니처는 유지하되, true 분기에서 노무사용 행 생성:
   - 시스템 계산값(`emp.totalWage`, `wageBreakdown.*`, `3.3%공제`) 사용 금지.
   - 추가로 `대체휴무사용/연차사용`도 컬럼화 (`emp.substituteLeave?.used ?? 0`, `emp.annualLeave?.used ?? 0`).
   - 나머지는 기존 fullRow에서 인건비/3.3%·계약휴무 위치 조정만.
5. PDF 렌더 분기:
   - `consultantMode`도 컬럼 17개 수준이라 `landscape` 유지.
   - 우측정렬 컬럼 인덱스 재계산 필요(헤더 변경 반영).
   - 합계 라인은 `consultantMode`일 때 `합계 ${grandTotalWage}원` 대신 `대상 직원 N명 / 영업일 N일` 류로 교체(시스템 계산 금액 노출 회피). `data` 기반으로 계산 가능.
6. 파일명·시트명:
   - `consultantMode` true 시 `노무사전송_${year}년${month}월_${current?.name}` / 시트명 `노무사전송`.
   - false 시 기존 `인건비정산_…` / `인건비정산`.
7. Excel `wch`도 새 컬럼 구성에 맞춰 재지정 (아래 §3 참고).

## 3. 내보내기 가독성 — 한 줄에 들어오게

### 공통 원칙
- 헤더 단어 짧게: `인건비(원)` → `인건비`, `대체휴무잔여` → `대휴잔여`, `대체휴무사용` → `대휴사용`, `보험구분` → `보험`, `급여유형` → `유형`, `계약시작/계약종료` → `계약시작/종료`.
- 사람이 읽는 컬럼은 폭 넓게, 숫자는 좁게.

### Excel `wch` 권장값 (consultantMode 기준 17열)
```
소속회사 14, 이름 10, 직위 8, 유형 6, 계약급여 12, 보험 8,
출근 6, 실휴무 7, 계약휴무 8, 대휴사용 7, 대휴잔여 7, 연차사용 7, 연차잔여 7,
계좌번호 18, 주민번호 16, 계약시작 12, 종료 12
```
fullHeaders(17열, 기본 정산)도 동일 패턴으로 재지정. 핵심: 계좌(18), 주민번호(16), 계약일(12), 인건비/3.3%(12).

### PDF (`jspdf-autotable`)
- `orientation: "landscape"` 고정 (두 모드 모두).
- `styles: { fontSize: 7.5, cellPadding: 1.2, font: "NanumGothic", overflow: "linebreak" }` — 폰트 8 → 7.5로 축소 + cellPadding 축소.
- `headStyles.fontSize: 7.5`.
- `tableWidth: "auto"`, `margin: { left: 8, right: 8 }`로 가용 폭 확보.
- `columnStyles`로 폭 명시(아래 mm 기준, A4 landscape 약 297mm 가용 281mm 기준):
  ```
  소속회사 22, 이름 16, 직위 12, 유형 12, 계약급여 22, 보험 14,
  출근 12, 실휴무 12, 계약휴무 14, 대휴사용 14, 대휴잔여 14, 연차사용 12, 연차잔여 12,
  계좌번호 30, 주민번호 24, 계약시작 18, 종료 18
  ```
  합 ≈ 278mm — 281mm 안에 1줄로 들어옴. 숫자 컬럼은 `halign:"right"`.
- `didParseCell`로 헤더 줄바꿈 방지: 길이 긴 헤더 사전 단축(위 §3 공통 원칙 적용)으로 해결.

## 4. 검증 (Code 측 push 전 필수)

1. `pnpm run build` 통과 (esbuild + vite 모두).
2. `pnpm tsc --noEmit` 또는 빌드 단계의 타입 체크 에러 0.
3. 수기 검증:
   - 근무현황 페이지: PC/모바일 폭에서 동일 카드 형식, 카드 펼침 시 테이블 정상 렌더, `employeeMonthlyShifts` 쿼리가 펼친 카드만 호출되는지 (네트워크 탭).
   - 인건비정산 페이지: 체크박스 라벨 "노무사전송용 (시스템 계산 급여 제외)", 기본(off) Excel/PDF가 기존 fullHeaders 결과와 동일.
   - 노무사전송용(on) Excel/PDF: 인건비·3.3%공제 컬럼 부재, A4 landscape 1줄 안에 모든 컬럼 표시(줄바꿈 없음).
   - PDF 파일명: `노무사전송_2026년5월_매장명.pdf`.
4. 리스크/롤백:
   - 영향: client UI만, tRPC 라우터·DB 무영향.
   - 롤백: 단일 커밋이면 revert 1회로 복원 가능. 두 페이지 변경을 별도 커밋으로 분리해도 무방(권장).

## 6. 미해결/판단 보류

- 노무사전송용 모드 PDF에서 합계 라인을 어떤 지표로 채울지 확정 필요 (잠정 `대상 N명 / 영업 N일`). Code 단계에서 합계 행 자체를 생략해도 무방하면 그 안이 더 깔끔.
- 카드 펼침 시 한 번에 한 카드만 허용할지(`expandedEmpKey` 단일) vs 여러 카드 동시 허용(`Set<string>`)은 현재 단일 유지. 다중 펼침 요구 시 별도 변경.
