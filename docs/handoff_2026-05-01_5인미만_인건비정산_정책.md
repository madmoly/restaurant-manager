### [8] 서명 게이트 검증
- 김정란 계약서가 구버전(환산 문구 없음)이면:
  - LaborCostPage에 "계약서 갱신 필요" 배너 표시
  - 정산 결과는 **현행 시간 비례식**으로 fallback (신정책 미적용)
  - StaffPage에서 재발급 클릭 → 신규 템플릿(환산 문구 포함)으로 전자계약서 발송 → 서명 완료 시점부터 신정책 적용

### [16] 소급 배치 검증
실행 전 dry-run 모드로 신정책 적용 결과 미리보기:
```bash
pnpm tsx scripts/recalculate-2026-q1.ts --dry-run
```
- 직원별 신정책 정산값 vs 기존 daily 합계 차이 출력
- 매장별·월별 보정값 합계 출력
- 사용자 검토 후 본 실행:
```bash
pnpm tsx scripts/recalculate-2026-q1.ts --execute
```
- 실행 후: LaborCostPage / MonthlySettlement / 대시보드에서 동일 값 표시 확인 (정합성 #13)
